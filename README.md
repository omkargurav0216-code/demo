# NPTEL Quiz Master

An interactive quiz application for practising NPTEL questions through weekly question banks.

## Features
- 12 weekly question banks in JSON format.
- Single-choice, multiple-choice, and numerical questions.
- Instant answer feedback and score calculation.
- Quiz retry functionality.
- Progress saved locally in the browser.

## Tech Stack
- React
- Vite
- Tailwind CSS
- JavaScript

## Getting Started

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```

The production files are generated in the `dist` directory.

## Deployment

The frontend can be deployed on Netlify as a static website.

**Note:** This version uses built-in weekly question banks and does not require a backend server.
